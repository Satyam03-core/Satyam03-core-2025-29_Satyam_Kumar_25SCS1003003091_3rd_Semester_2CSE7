# 🤖 CIVIK – Offline AI Civic Assistant

> **Democratizing AI Resources through Offline-First, Multimodal AI**

CIVIK is an **AI civic assistant** designed to make AI accessible to everyone, especially in **low-connectivity and resource-constrained environments**.

It combines **speech, text, vision, AI models, and hardware sensors** to provide intelligent assistance without relying heavily on a constant internet connection.

## 🚀 Live Demo

🔗 https://civik-xi.vercel.app/

## ✨ Features

* 🎙️ **Offline Speech-to-Text** using VOSK
* 🧠 **AI Intent Detection** using Qwen
* 🤖 **Response Generation** using LLaMA 3B
* 🔊 **Text-to-Speech** for voice responses
* 📷 **Camera-based Input Processing**
* 🔌 **Hardware Sensor Integration**
* 🌐 **Offline-capable AI responses**
* 🗣️ **Multimodal Interaction** – Voice, Text & Vision

## ⚙️ How It Works

```text
User Input
   ↓
Voice / Text / Camera / Sensors
   ↓
VOSK (Speech-to-Text)
   ↓
Qwen (Intent Detection)
   ↓
LLaMA 3B (Response Generation)
   ↓
Text / Speech Response
```
